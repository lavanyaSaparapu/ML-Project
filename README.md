# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview

This project uses Machine Learning classification techniques to predict the **10-year risk of Coronary Heart Disease (CHD)** based on patient health and lifestyle information from the Framingham dataset.

The project demonstrates the complete Machine Learning workflow, including data loading, exploration, preprocessing, visualization, and classification.

## 🎯 Objective

The main objective is to build a classification model that predicts whether a person is at risk of developing coronary heart disease within the next 10 years.

### Target Variable

- `TenYearCHD` - Indicates the 10-year CHD outcome.

## 📊 Dataset Features

The dataset contains features such as:

- Gender
- Age
- Education
- Current Smoker
- Cigarettes Per Day
- Blood Pressure Medication
- Prevalent Stroke
- Hypertension
- Diabetes
- Total Cholesterol
- Systolic Blood Pressure
- Diastolic Blood Pressure
- BMI
- Heart Rate
- Glucose

## 🛠️ Technologies Used

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Project Workflow

1. Import required libraries
2. Load the Framingham dataset
3. Explore the dataset
4. Analyze features and target variable
5. Handle missing values
6. Perform data preprocessing
7. Visualize important patterns
8. Build classification models
9. Evaluate model performance
10. Predict 10-year CHD risk
